# MediQueue — Hospital DSA Project
# ====================================
# Ye 5 files hain is project mein:
#
# hospital-dsa.html     → Puri website (browser mein open karo)
# 1_priority_queue.py   → Emergency Triage — heapq
# 2_binary_search_tree.py → Patient Records — BST
# 3_graph_bfs.py        → Hospital Navigation — Graph + BFS
# 4_stack.py            → Appointments — Stack
#
# Python files chalane ka tarika:
#   python 1_priority_queue.py
#   python 2_binary_search_tree.py
#   python 3_graph_bfs.py
#   python 4_stack.py
#
# Website chalane ka tarika:
#   hospital-dsa.html ko Chrome mein open karo
# ====================================

# DSA Summary:
# +---------+--------------------+-------------+------------+
# | Feature | Real Problem       | DSA          | Complexity |
# +---------+--------------------+-------------+------------+
# | Queue   | Kaun pehle treat   | Priority Q   | O(log n)   |
# | Records | Patient dhundna    | BST          | O(log n)   |
# | Map     | Shortest path      | Graph + BFS  | O(V+E)     |
# | Appoint | Undo appointment   | Stack        | O(1)       |
# +---------+--------------------+-------------+------------+
